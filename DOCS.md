## Color Palette

#0B2F1D (Deep Forest Green): Warna latar belakang utama atau sidebar untuk kesan misterius dan kokoh.
#1E5631 (Emerald Moss): Warna aksen utama untuk elemen aktif, tombol primar, atau status sukses.
#A3B899 (Sage Mist): Warna hijau muda keabu-abuan untuk teks sekunder, batas kontainer, atau grafik border.
#EBF2EA (Eco White): Warna latar belakang konten utama agar mata tidak cepat lelah saat membaca data.
#D4AF37 (Raw Amber/Gold): Warna aksen premium untuk menyoroti data penting, metrik utama, atau status warning.
